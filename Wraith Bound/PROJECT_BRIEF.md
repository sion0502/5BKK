# Wraith Bound 프로젝트 브리프

> 작성일: 2026-08-21  
> 작업 기준: `Assets/ExternalAssets/` 폴더의 원본 에셋 파일은 우선 분석 범위에서 제외  
> 개발 원칙: 기존 코드는 최대한 건드리지 않고, 필요한 경우에만 최소 범위로 수정

## 1. 프로젝트 개요

`Wraith Bound`는 괴물을 피해 특정 아이템을 모으고 탈출하는 1인칭 공포 생존 게임이다. 전체적인 분위기와 플레이 감각은 `그림자복도`에서 영감을 받았으며, 어두운 공간을 탐색하면서 적의 추격을 피하고 제한된 자원을 활용하는 긴장감을 핵심으로 한다.

## 2. 핵심 플레이 목표

플레이어는 맵을 탐색하며 탈출에 필요한 아이템을 수집한다. 탐색 중에는 괴물의 시야, 소리, 추격 패턴을 피해야 하며, 숨기, 도망, 아이템 사용을 상황에 맞게 선택해야 한다.

최종 목표는 다음과 같다.

1. 맵 내부에서 목표 아이템을 찾는다.
2. 괴물의 추격을 피하며 생존한다.
3. 탈출 조건을 만족한 뒤 출구로 이동한다.
4. 탈출에 성공하면 챕터를 클리어한다.

## 3. 주요 게임 요소

| 요소 | 설명 |
| --- | --- |
| 플레이어 | 1인칭 시점으로 이동, 달리기, 웅크리기, 상호작용을 수행 |
| 괴물 | 플레이어를 탐지하고 추격하는 위협 요소 |
| 아이템 | 탈출 조건, 생존 보조, 장비 사용 등으로 활용 |
| 맵 | 병원 또는 폐쇄된 실내 공간을 중심으로 한 공포 탐색 공간 |
| 숨기 | 캐비닛, 침대, 사물 뒤 등에서 일시적으로 추격을 회피 |
| 탈출 | 특정 아이템 수집 또는 조건 달성 후 출구를 통해 클리어 |

## 4. 개발 시 우선순위

### 4.1 먼저 완성해야 할 것

- 플레이어 기본 조작 안정화
- 괴물 탐지와 추격 로직 안정화
- 아이템 수집과 인벤토리 흐름 정리
- 탈출 조건과 클리어 흐름 구현
- 메인 챕터에서 시작부터 탈출까지 가능한 플레이 루프 연결

### 4.2 이후 다듬을 것

- 괴물별 차별화된 행동 패턴
- 사운드 기반 긴장감 강화
- 맵 랜덤성 또는 경로 다양화
- 아이템 밸런스 조정
- UI, 연출, 피드백 개선

## 5. 작업 범위 메모

현재 프로젝트에서 `Assets/ExternalAssets/` 폴더는 대부분 외부 모델, 프리팹, 사운드, 텍스처 등 에셋이 모인 공간이다. 분석이나 구조 정리를 할 때는 외부 에셋 자체보다 다음 항목을 우선 확인한다.

- `Assets/Scripts/`
- `Assets/Scenes/`
- `Assets/Prefab/`
- `Assets/Resources/`
- `ProjectSettings/`
- `Packages/`
- 기존 문서 파일

단, 특정 기능이 외부 에셋의 프리팹, 모델, 머티리얼, 애니메이션에 의존하는 경우에는 필요한 범위에서만 `Assets/ExternalAssets/` 내부를 확인한다.

## 6. 코드 수정 원칙

대형 팀 프로젝트이므로 기존 코드 변경은 최대한 보수적으로 진행한다.

1. 기존 기능을 먼저 파악한 뒤 수정한다.
2. 동작 중인 코드는 불필요하게 리팩터링하지 않는다.
3. 새 기능은 가능하면 새 스크립트나 독립 컴포넌트로 추가한다.
4. 기존 스크립트를 수정해야 한다면 변경 범위를 작게 유지한다.
5. 팀원이 작업 중인 파일이나 의도가 불분명한 코드는 임의로 되돌리지 않는다.
